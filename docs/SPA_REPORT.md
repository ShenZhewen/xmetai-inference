## 1 概述与定位

**一句话定义。** 不改任何权重、不做任何训练，只在推理图上新增**一个**输入 `spw/xi`
（每步 T×R = 3×16 = 48 个 float32），把一个**低秩、空间平滑、时间上带 AR(1) 记忆**的
随机场以乘性增益加到骨干的低分辨率潜状态上：

```
z ← z ⊙ (1 + σ·n),    n[b,c,tok] = Σ_r ξ_t[b,r] · u_r[c] · v_r[tok]
```

所有成员**共用同一份图**，成员间差异只来自 ξ 的随机种子 ⇒ 51 个成员不需要 51 份模型
（对照 SPW 权重扰动：51 份扰动图 + 51 个 session + 成员集落盘）。

**在整个扰动方法族里的位置。** 项目把「确定性 ONNX → 集合」的实现拆成两条互不相同的腿：

| 腿 | 改什么 | 时间结构 | 代码 |
|---|---|---|---|
| SPW 权重扰动（m1a） | `W~ = W ⊙ (1 + σξ)`，逐成员落盘冻结权重 | τ → ∞（轨迹全程冻结） | `weights/spw.py` |
| **SPA / latent AR(1)（本报告）** | **潜状态乘性强迫，每步注入** | **0 < τ < ∞ 连续可调** | **`weights/spa.py` / `weights/spa_pt2.py`** |

两条腿正交、可叠加（`resolve_stack_path`）。集合图自带的图内噪声（τ → 0，每步重抽）
只作为 τ 轴的另一个概念端点；它的幅度旋钮（σ × k，原 `noise_scale.py`）已于 2026-10-20
移除（实测无收益，见 `docs/PAPER.md` §3.3.10）。SPA 与另两条的本质差别是**它把噪声的
时间相关做成了连续自由度**：SPW 的 τ = ∞、图内噪声的 τ = 0 都是它的端点（见 §2.2）。

**当前状态（一句话版）。** 位置已定死（decoder 入口），σ/τ/a(t) 三轴已整批结算
（v14 十臂 × 三起报）；**当前最好配置是 `aB`**（时变包络，校准 RMS|SER−1| = 0.140，
三起报全胜整族常数 σ）；要一个数就用常数 σ = 0.10。详见 §6。

## 2 动机与机理

### 2.1 出发点：缺的是增长率，不是幅度

目标骨干（FGVP/GDN）欠离散——短中时效 spread 只有参考集合的约 1/4——但**均值场健康**。
此前 SPW 的系统消融（README §2C–2M）已经把结论收窄到一句话：

> `spread(lead) ≈ f(σ)^p(lead)`，指数 p 只由**注入点在骨干上的位置**决定，与 σ、秩、
> 注入时刻都无关。σ 只是一个幅度旋钮；四个形状自由度（组内注入位置 / σ / 秩与结构 /
> 分段刷新）逐一扫过，**全部平或反向**。

物理集合（IFS-ENS）用的 SPPT 扰动**参数化倾向项**，其噪声带 AR(1) 时间相关、在时间上
累积。神经网络的「倾向项」对应物是**每一步的潜变量残差更新**。m3（图内随机算子）的
失败诊断正好是反证：每步重抽的白噪声只有冻结权重的 1/3–1/8 离散度——白噪声每步被 Δt
平滑掉。**所以缺的从来不是幅度，是增长率。**

### 2.2 核心论证：时间相关是权重扰动结构性碰不到的

| 随机性来源 | 抽取时机 | 时间结构 |
|---|---|---|
| 图内自带噪声（`RandomNormalLike`） | 每步重抽，步间无记忆 | τ → 0 端点 |
| SPW 权重扰动 | rollout 开始前抽完、全程冻结 | τ → ∞ 端点 |
| **SPA（本方法）** | **每步注入，带 AR(1) 记忆** | **0 < τ < ∞** |

⇒ SPW 与图内噪声不是两种机制，是同一条轴的两个端点；SPA 把整段中间夹出来。
噪声必须**每步注入且带记忆** ⇒ 不能像 SPW 那样烤进权重——烤进去就退化成 τ → ∞。
这也解释了论文（Adamov et al. 2026）里「沿轨迹刷新只对 SFNO 有效」的现象：SFNO 的
噪声落在最粗谱模上、是唯一耐用通道，刷新等于反复往耐用方向注；SPA 把这个解释做成
了**可控实验**（τ 管「注得多持久」、length_scale 管「注在哪一档尺度」）。

### 2.3 买到的是什么

「改形状」买到的是**「往中长时效加离散度而几乎不动短时效」这个自由度**：

- SPW 补长时效只能拧 σ ⇒ 短时效一起爆（S2B 的 +24~72 h SER 已 1.20–1.39）；
- AR(1) 的离散度比随时效单调爬升（第 5 天到顶），理论上可以只抬中长时效。

**实测边界（必须跟着带）**：这条收益是**锚点相关**的——在锚点效率高的 decoder 入口上，
τ 的效应会部分退化为幅度等效（§6.2）；且 τ 加不了第一天的离散度（+6 h 比值恒 1.00），
绝对意义上的「短时效加权」是初值扰动（IC）的地盘，SPA 给不出。

## 3 方法构造

### 3.1 时间轴：平稳化 AR(1)（驱动侧，每 6 h 一步）

```
ξ_{t+1} = ρ·ξ_t + sqrt(1−ρ²)·ε_t ,    ε_t ~ N(0, I),    ρ = exp(−Δt / τ)
```

- ξ_t ∈ R^R（R = rank，默认 16）⇒ **平稳、单位方差、相关时间 τ** 的随机过程；
- `sqrt(1−ρ²)` 那一项让 `Var(ξ) ≡ 1` 对**所有 τ** 成立 ⇒ **τ 只改自相关，不改幅度**。
  这是「τ 消融是干净单变量实验」的全部理由：同 σ 两臂在 +6 h 的 spread **逐位相同**
  （6.326 / 6.326）——不是幅度效应，是纯形状效应；
- 实测口令（`--hour-interval 6`）：τ=3 天 → ρ = **0.9200**；τ=1 天 → **0.7788**；
  τ=0.05 天 → **0.0067**（≈ 每步重抽 = m3 的时间结构）；τ=∞ 用 τ=10⁶ 天实现
  （spec 要求 τ > 0）；
- 两个端点：τ→0 = 图内噪声的每步重抽；τ→∞ = SPW 的全程冻结。**τ 轴把 m3 / m1a
  当成两个端点夹在中间，是真正的新自由度。**

### 3.2 空间 + 通道轴：低秩基（图内，烘焙成常量）

```
空间基 V[N_tok, R]  : 白噪声 → 高斯低通(相关长度 length_scale，单位 token) → 去 DC → QR 正交化
通道基 U[C, R]     : 随机正交
每步的场            n[b,c,tok] = Σ_r ξ[b,r] · Uᵀ[r,c] · Vᵀ[r,tok]
```

- **能量配平**：取 `s = σ·sqrt(C·N/R)` 折进 U，强制 `‖u_r‖ = ‖v_r‖ = 1` 后
  `RMS(n) = σ·sqrt(Σξ²/R) ≈ σ` ⇒ **σ 就是「潜变量的相对扰动幅度」**，无量纲、与
  SPW 的 σ 同语义、跨配置可比，**不参与配平**；
- **去 DC 不是美学**：不去掉就是「整场一致偏移」，正是论文报告的主失效模式（区域平均
  过离散、空间平均 SSR 1.6–3.2）；本骨干的失效方向是**欠**离散，更不能往那边加；
- **退化兜底**：length_scale 相对网格过大时，低通会把除 DC 以外的模压成**精确的 0**，
  去 DC 只剩数值残差，QR 会造出带均匀分量的基——恰好落进主失效模式。`build_basis`
  逐方向检查「去 DC 后能量 ≥ 低通前能量的 1e-8」，不达标**退回白噪声**并
  `log.warning` + `report["fallbacks"]` 记账。90×180 网格上阈值在 ls ≈ 88 ⇒ 阶梯
  （≤32）从未触发，但换小网格必须核 `spw.ar1.fallbacks`。

### 3.3 注入（乘性增益）

```
z' = z ⊙ (1 + σ·n)
```

- 乘性 ⇒ 与 SPW 的 σ 语义一致；`σ = 0` 是**合法的空转对照**（gain 恒为 1，输出与源图
  **逐位相同**）——`state_s00` 那条臂就是它，改写链的等价性回归也用它；
- 注入目标默认 = 骨干**低分辨率潜状态**出口（论文四个骨干的优胜注入点都紧邻这里），
  具体锚点见 §6.1；
- σ = 0.04 是 σ² 量级的相对扰动，落在「不把模型推出流形」的经验区间（对照：把噪声
  推到网格尺度的 `ens_k20` 让 spread ×2.4 的同时 RMSE ×7.5、activity_ratio 掉到 0.61）。

### 3.4 四个（+二个）旋钮总表

| 旋钮 | 字段 | 默认 | 拧它改什么 | 实测判定 |
|---|---|---|---|---|
| 幅度 | `sigma` | 0.04 | **加多少**（RMS 语义） | 主控校准；σ\*≈0.092 过零、响应凹/饱和（§6.3） |
| 时间 | `tau_days` | 3.0 | 额外离散度**堆在哪段时间**（速率旋钮） | 真杠杆，**必须与 σ/a(0) 配平后再扫**（§6.2） |
| 空间 | `length_scale` | 32 | 名义上「进哪个尺度」 | **无效**：ls ≥ 8 之上退化成幅度旋钮（§6.6） |
| 秩 | `rank` | 16 | 扰动预算集中度（效率轴） | 不是形状轴；rank > channels 直接拒绝 |
| 时变幅度 | `amp_profile` | None | a(t) 分段线性包络（σ 随时效的曲线） | **成立**：aB 当前最好（§6.4） |
| 注入锚点 | `targets` | `latent_state` | 每单位 σ 换多少 spread（效率） | **全项目效应量最大、已定死**（§6.1） |

另有 `demean_members`（跨成员去均值）：设计动机是把「ξ 样本均值踢集合平均场」的耦合
拆掉，**实测作废**（§6.5），两条 config 不用再跑。

### 3.5 两个辅助自由度（驱动侧，不进图指纹）

- **`amp_profile` a(t)**：σ 是常数而「校准所需有效 σ」随时效单调上涨（实测 6h→360h
  要涨约 3.5 倍），一个标量给不出曲线。折线 `((step, 倍数), ...)`，step 为 0 基模式步
  （一步 6h），分段线性、两端外推取端点。**只在驱动侧乘出口 ξ、绝不写回状态**——写回
  会让递推变成被自身包络驱动的非平稳过程，τ 不再是相关时间。
- **`demean_members`**：本地重放全体成员的 ξ 流（种子逐个与真实成员相同，含
  `slot = m % world_size` 的卡数口径），出口 ξ 减全体样本均值。见 §6.5。

## 4 实现

### 4.1 ONNX 后端（FGVP/GDN）：落盘改写

入口 `build_forcing_model`：读源图 → 解析目标 → 算基 → 注入 → 落盘 → 校验，产物
`<stem>.ar1-<指纹>.onnx`（FGVP 实测：19 个新节点、87.4 MB、2.9 s）。

每个目标的算子链（`Split` 三目标共用；`inject_forcing`）：

```
spw/xi [B,T,R]
  └─ Split(axis=1)          -> T 份 [B,1,R]
       └─ Reshape([0,R,1])   -> [B,R,1]
            └─ Mul(Vt [1,R,N])          -> [B,R,N]    先逐 r 缩放
                 └─ Transpose(0,2,1)     -> [B,N,R]    MatMul 收缩最后一维
                      └─ MatMul(Ut [R,C]) -> [B,N,C]
                           └─ Add(1) -> Mul(目标张量)   z ⊙ (1 + n)
```

每目标 +6 节点（fp16 图再加一个 Cast）、+2 个常量（Vt 16200×16 + Ut 16×512 ≈ 1 MB）。
插入位置 = **每个目标自己的第一个消费者之前**，不依赖目标彼此相邻。

两个「只在 gdn2 上成立」的隐含假设，换骨干后修过（`FORCING_FORMAT` v2→v3）：

| 假设 | gdn2 成立原因 | 换骨干（opset 18+ / fp16）后 | 修法 |
|---|---|---|---|
| `Split` 可只给输出个数 | opset 17 靠均分 | 建会话直接拒收 | 按图自己声明的 opset 决定加不加 `num_outputs` |
| 增益可与目标直接 `Mul` | fp32 | fp16×fp32 被拒（T 绑定两种类型） | 链全程 fp32，只在最后 Cast 到目标类型 |

**教训（制度化）**：图改写层的可移植性不能靠结构自检背书，必须过真实的会话创建；
且指纹不含「构造函数版本」，改写逻辑修对而旧图还在时会**静默复用坏图**——所以
`budgets()` 里带 `format` 常量，改图方式就 +1，全部既有图指纹失效重建一次。

### 4.2 pt2 后端（FuXi-2.1，torch.export）：内存改写

同一套 `LatentForcingSpec / build_basis / Ar1Driver / LatentStepStream`，公式一行没改，
换掉的只有「把强迫接进图」那一层（`latent_pt2.py`，`attach_forcing` 在 `ep.module()`
之前就地注入、改完 `recompile()`、**不落盘**）。三处被迫的差异：

| | ONNX（FGVP） | pt2（FuXi-2.1） |
|---|---|---|
| 改写时机 | 落盘一份 `*.ar1-<指纹>.onnx` | 内存图上插节点 + recompile，无产物无 metadata |
| 注入点定位 | 节点名后缀 / `latent_state` 别名 | **从权重占位符沿单链回溯**：`p_model_decoder_layers_{k}_mlp_w2_weight` → `aten.linear` →（透明算子）→ 残差 `aten.add` = 第 k 层末残差流；别名 `layer_stream` / `layer_stream:0,10,20` |
| ξ 的入口 | 新增图输入 `spw/xi` | GraphModule **属性** `spw_xi`（get_attr 读，驱动侧每步就地 `copy_` 覆写）——图签名固定塞不进新输入；属性名必须用下划线，fx codegen 会把名字写进生成代码，`/` 非法 |

FuXi-2.1 实测布局：tokens=28800（120×240）、channels=1536、30 个 decoder 层、全程 fp16，
潜状态 `[1, 28800, 1536]` 与 FGVP 同构 ⇒ `build_basis` 直接复用。每目标 5 节点
（`select → mul → mm → add → mul`）。**grid 必须显式给**：fx 图推不出 rows×cols，
网格猜错会把低通平滑落在错的轴上、场被静默搅乱而所有结构检查全绿。

四个会**静默**失效的坑（自检已逐一钉住，223 条全过）：

1. **回溯别假设 `linear → add` 一步到位**：真链路是 `linear → clone → mul(×[1,1,C] 调制)
   → add`。修法 = 从权重占位符沿**单链**走、每步校验「消费者恰好 1 个（分叉即报错）
   / 只穿透明算子（clone/_to_copy/view/reshape/mul/div）」，链长上限 8。
   注错层的所有结构检查都会全绿，只有数值参考能发现。
2. **`inserting_after` 是一个插入点不是追加**：同块连续 create_node 全插同一位置、后建的
   排前面；逆序图照样 recompile 成功，只在 codegen「先用后定义」或 unlift `KeyError` 才炸。
   修法 = 每建一个节点就把锚点挪过去接力插；并把 `gm.graph.lint()` 变成审计断言
   （`report["topological"]`）。
3. **`setattr` 换张量 = 静默退化成确定性预报**：`ep.module()` 的 unlift 是 deepcopy 新建
   GraphModule，`spw_*` 属性带过去的是**同一批张量的引用**；每步 `setattr` 新张量只改到
   一个副本，真正在跑的那个恒为 0 ⇒ gain 恒 1 ⇒ 所有成员逐位相同且**无任何报错**。
   修法 = 持有 unlifted module，每步 `copy_` 就地改写；backend 加断言：注入了图却丢了 gm
   引用直接 RuntimeError。
4. **CLI `--targets` 的逗号会把 `layer_stream:0,10,20` 拆开**：拆出的裸数字做节点名后缀
   匹配会**碰巧**命中无关节点（实测注到了 channels 不同的节点上）。两头都堵：CLI 窄合并
   + `resolve_fx_targets` 对裸数字一律拒绝。

另外：fp16 下算 `‖Vt‖` / 隐含 σ 必须**先转 float32**（28800×16 的 fp16 平方和会溢出成
Inf）。真实模型（fuxi-2.1.pt2，3.9 GB）的图结构验收 2026-09-30 本地已过（3 注入点回溯
到位、15 新节点、`tokens=28800/1536/(120,240)`、`σ_implied=0.04`、`ρ=0.92`、拓扑序过、
unlift 路径确认共享张量）；**端到端出数待跑**。

### 4.3 驱动侧：状态机（两后端共享）

- **`Ar1Driver`**：持有 ξ_t，`value/row/advance/reset`。成员独立性来自熵
  `(seed, 7919, member_index, slot)`；`reset` 重抽不重置随机流（「重抽 = 新轨迹」，
  整个任务的抽样序列仍可复现）。
- **`LatentStepStream`**：在「runner 逐轨迹调 forward（x.shape[0] 恒 1）」的编排下决定
  本次 forward 拿第几行 ξ、何时 reset / advance：
  - 一行 = 一条轨迹**独立**的 AR(1) 流；step 变化 = 新模式步（整批 advance 一次）；
    step == 0 = 新轨迹批（全部行重抽）；
  - **width 语义**：`rollout_batch > 1` 时一次 forward 堆 k 条轨迹，发号返回起始行、
    槽位前进 k，后端 `ar1.row(index, k)` 取 `[k,T,R]` 一次喂进。**width>1 与 rb=1 逐位
    同流** ⇒ rollout_batch 对集合中性（有回放测试钉住）；
  - **进程 rank 必须计进熵**：只开 latent 时 member_index 恒 0、成员身份 = 行号，多卡按
    成员切时不含 rank 会让各 rank 的 ξ 逐位相同 ⇒ **静默重复成员**；
  - a(t) 倍数按 step 定一次（`amp_at(step)`），同一 step 内多个 width 块共享。
- **原始接线错误（历史，已修）**：width 恒 1 却按 k 条轨迹喂块 ⇒ 块内成员拿相邻行、
  成员几乎重复、集合静默欠散——成员间仍互不相同所以 check 不报错，这正是它危险的地方。

### 4.4 图指纹：一个刻意的方法学设计

`LatentForcingSpec.budgets()` 进指纹的字段 = `targets / sigma / rank / length_scale /
tokens / channels / grid / seed / input_name / format`。

**`tau_days`、`hour_interval`、`amp_profile`、`demean_members` 刻意不进**——它们只在
驱动侧起作用、不改图。两个后果，一好一坏：

- 好：**换 τ / 换 a(t) 曲线 / 开去均值都复用同一份图**（85 MB），「A32 vs A32T0」因此
  成为共用同一份图的单变量对照，τ 轴的消融成本严格低于 σ 轴（v14 十条臂共图是刻意的）；
- 坏：这些字段**不留下任何图痕迹**，曲线抄错一个折点、或 step 口径差一格，产出的臂
  照样跑完出数，只是**它是另一条臂**——`ar1_amp_audit.py` 就是为抓这类静默错臂写的
  （它实测抓到过：aB 的 config 把 1 基折点抄成 0 基，**整条曲线晚 6h**；且按实测结论
  「时均配对反而更好，别去修」——见 §7.3）。

反过来 **`targets` 在指纹里 ⇒ 换锚点必须重导图**——这是位置轴（§6.1）贵、并冻结在
decoder 入口的原因。

### 4.5 审计与自检覆盖

- `latent audit <图>`：读 metadata + 结构，确认「驱动侧喂的 ξ 真的被消费了」（输入在、
  目标在、spw/ar1 节点数对）。**pt2 没有可审计的落盘产物**，audit 会明确拒绝；
- `self-test`（223 条）钉住：目标解析与回落、布局探测、4 维目标拒绝、**σ=0 逐位等价**、
  numpy 参考逐位一致、**同 ξ 两次前向逐位相同**（图内无随机算子——与 m3 的分水岭）、
  消费者全改接且只改一次、基正交 / 无 DC / 隐含 σ / 退化兜底 / rank 上限、ρ 解析值与
  实测 lag-1 一致、平稳方差、τ 单调、member/槽位/rank 独立性、reset、无消费者报错；
  pt2 侧另有回溯三写法、错例图（层内夹 sigmoid / 链路分叉）拦截、逐列数值参考
  （列↔层错位立刻分家）、重复注入拒绝、裸数字拒绝等；
- `build_forcing_model` 打印的硬检查：`‖Vt‖ = sqrt(rank)`、**基隐含 σ = 设定值**（「σ
  语义没被基的缩放带偏」的唯一硬检查）。

## 6 实验结论（按轴组织）

> 总原则（一条就够）：**判据是 SER / CRPS，不是 spread 的大小**；所有判定必须
> **三起报符号一致**才认（§7.1）。

### 6.1 位置轴（注入锚点）：效应量最大、已定死 ⭐

三个候选位置，现跑的全部臂都在 decoder 入口：

| 别名 | 锚点 | 层级 |
|---|---|---|
| `prior` | `cat_9` | 三个 VAE 编码器出口 Concat（潜先验入口），下游还有 prior 头 → 采样 → 整条主干 |
| **`main`（现状）** | `add_35782/787/792` | **decoder 入口**（latent_mixer 三个 group 出口，进 decoder 之前） |
| `head` | `add_40939/46096/51253` | decoder 之后、预测头之前（**从未出数，空白**） |

实测（07-02、z500、51 成员、τ=3d，全部对裸跑的 Δ%）：

| 锚点 | σ | 24h spread | 24h SER | 24h CRPS | 240h ACC |
|---|---|---|---|---|---|
| `cat_9` | 0.04 | −0.14%（底噪内） | −0.62% | +0.61% | +0.65% |
| `cat_9` | **20**（500×） | +14.79% | +15.20% | −2.04% | +3.40% |
| **decoder 入口** | **0.04** | **+44.98%** | **+45.80%** | **−5.31%** | **+6.18%** |

⇒ **decoder 入口用 1/500 的幅度拿到比 `cat_9` σ=20 更大的 CRPS/ACC 增益；同 σ 只换锚点
效应差 ≥300 倍**（分母在底噪内，比值是下界）。机理：位置改的是**分歧增长率**不是幅度——
`A`（只扰 decoder_group）的 +240h 标定比只有 0.138 且随效下降，说明增长率本身太低；
「幅度不够」的表现应是恒定偏小的比值。**本骨干缺的是增长率，不是幅度**；往上游挪
（输出渲染 → latent_mixer recurrent 核 → latent 状态入口）单调改善。

边界两条：

- **组内**换位置（`T`，仍在 latent_mixer 内）不是形状自由度，只缩放幅度（k ≡ σ×0.37，
  平）；**跨组**（D/G/H）k 不平但量级不够翻案（H 末段比头段高 38%，门槛 ×4.3）⇒
  **不要从「T 平」外推出「注入点无所谓」**；
- **位置已锁定、不要再动**：已在实测最优一端（vs prior；head 无数据），且换锚点必须
  重导图（`targets` 在指纹里，§4.4）。

### 6.2 时间轴（τ）：真杠杆，且是第二个「形状」旋钮 ⭐

**第 6 轮判决（P1 成立）**——同图、同 σ=0.04、同 ls=32、同 51 成员，只换 τ：

| lead | +6h | +24h | +48h | +72h | +120h | +168h |
|---|---|---|---|---|---|---|
| 离散度比 `A32`(τ=3d) / `A32T0`(τ=0.05d) | **1.00** | 1.48 | 1.91 | 2.13 | 2.24 | 2.24（饱和） |
| `A32` SER | — | — | **1.094** | **1.092** | — | 0.72 |

+6h 逐位相同（τ 不改平稳方差）⇒ 纯形状效应；`A32T0` 的 SER 全程只有 0.30–0.57
（无记忆端从来没标定上过）。CRPS 自 +24h 起全面更低（+168h：190.0 vs 207.2）。
在重叠 51 成员窗口上 `A32` 对生产候选 `S2B` 全面小幅胜（RMSE 407.0 vs 411.9，
CRPS 182.3 vs 184.1，配对 95/25、90/30）。

**三条边界（原版）**：+6h 恒 1.00 ⇒ τ 加不了第一天的离散度；+120h 后冻在 2.24 ⇒
买的是「前 5 天累积更快」；2.24 是落点可调范围不是精度提升。

**第 13 轮修正**：入口锚点上 48–240h 单调序复现（t005 < t1 < s04 < tinf，且 +6/24/48h
比值几乎逐位重合），但 **+120h 之后不冻住**、`t005` 在 240h 的 spread 低过 σ=0 对照
2.83% ⇒ **τ 同时是幅度旋钮**（长时效上把额外离散度抽掉），「只改时间分配」只在中段成立。

**第 14 轮翻案（最终版）**：`t005s15` vs `s15`（同 σ=0.15，只换 τ 3d→0.05d）——
spread 与 SER 逐时效全线 **−43%~−6%**、七个时效点 × 三个起报**全部同号**；τ 的作用是
**改离散度随时效的增长斜率**（spread@24 −27%、spread@360 只 −9%）。它不是免费的：
短时效（24~120h）rmse/crps 3/3 更好（72h rmse −5~−12%）、**240h 起 3/3 更差**。
⇒ **τ 与 a(t) 是同一类（形状）旋钮的两个入口，必须联合扫、别单独定**；扫 τ 必须在
σ/a(0) 已配平的档上扫，否则读到的是「过散被压回来」。

另：锚点效率高时 τ 退化为幅度等效（集合图入口上 τ=3 相对 τ=0.05 只有约 1.8× 的 σ 等效，
CRPS 差全部由 spread 解释）——「τ 有用」是锚点相关的，不是无条件结论。

### 6.3 幅度轴（σ）：主控校准，边界三条

- **σ\*≈0.095 复现**：24h 三点拟合 `SER ≈ 0.327 + 2.14σ + 52.8σ²` 得 σ\*≈0.095；
  v14 实际 σ 网格插值实测 σ\* = 0.107 / 0.087 / 0.082（均值 **0.092**）。s12 已越过
  σ\* 25% ⇒ **s12 不是好探针**；
- **σ→SER 是凹的（饱和），不是二次**：σ>0.08 之后二次外推系统性高估（s12 高 0.10~0.14、
  σ=0.15 高 0.25~0.36）⇒ **σ>0.08 别再用二次外推**；
- 「312/360h 上 σ=0 最好」在第 14 轮被推翻（σ 阶梯三起报全部单调下降），但**别读成
  「σ 赢了长时效」**：分解后 σ 优势里幅度项 −44%~−63%、形状项基本不动 ⇒ 是幅度效应
  （集合场本来就幅度过强，压小就赚），不是技巧。

CRPS 跟着 σ 单调改善，效应量 6~15%（24h：s04 −5.6%、s08 −10.5%；240h s08 −14.5%/
−8.8%），比臂间那些 1~3% 大一个量级 ⇒ **σ 是主控**，但常数 σ 两头只差 27%（SER@24
=1.08 / SER@360 = 0.85 @σ=0.10），「必须时变」降级为「时变买 ~15% 校准改善」。

### 6.4 时变包络 a(t)：成立，`aB` 是当前最好配置

v14 校准总账（口径：每起报 60 时效的 RMS|SER−1|，再三起报平均，越小越好）：

| 臂 | 整体 | 备注 |
|---|---|---|
| **`aB`**（照 σ*(t) 实测表 1.76×→6.13×） | **0.140** | **三起报全胜整族常数 σ**，每列第一 |
| 最佳常数 σ=0.100（插值假想臂） | 0.160 | 要一个数就用它 |
| s12 / s08 / s12… | 0.187 / 0.191 | |
| s15（aB 的平坦对照） | 0.280 | |
| aA（线性 1.0→3.0） | 0.307 | **亏**：a(0)=1.0 坡起太低 |
| s00 | 0.426 | 零强迫基线 |

- **机理与原设想不同**：短时效校准由 **a(0)** 定，不是时均 σ_eff ⇒ 原设计的「s08↔aA
  时均配对」是错的配法，`aA` 的真对照是 `s04`。**设计包络先把 a(0) 顶到 s04 档再往上爬**；
- aB 相对常数 σ 的赢面集中在 120~240h——每个常数 σ 都在那个窗口抬头；
- aB 的折点来自 s00/s04/s08 三档反解的 σ\*(t)/0.04 表（288h 点因响应指数异常剔除），
  **循环论证靠 07-10/07-18 两个起报的同向性闸住**（事前定死：只有 07-02 好 ⇒ 拟合噪声，作废）。

**aB 还差多远**（P4 逐尺度结算）：短时效标量 SER 九档均值 0.95（贴住），长时效均值
**0.87（偏窄 ~15%）**。可执行推论 = aB 尾段整体 ×1/0.87 ≈ **+15%**（spread 线性响应
于 a(t)），已落成臂 `aBt15`——**但这是外推不是实测**：σ→SER 饱和、aB 尾段等效 σ =
0.04×6.13 = 0.245 早已出标定区，且 0.87 的靶子只有 3 个起报（7 月那半段是复现，
**11 月才是唯一的样本外检验集**）。先用最便宜的配对实验（同起报 aB vs aBt15）验掉再
决定开不开整批。

### 6.5 去均值（demean_members）：作废，别再跑

`zm15` vs `s15` @312 rmse **+15.9/+14.1/+3.9**、@360 **+3.0/+19.8/+28.8**（3/3 更差），
spread 同档（±1.1%）；`zmaB` vs `aB` @312 +3.98/+4.82/+7.33（3/3 更差）。
⇒ 既不改离散度、又小幅弄差平均场。根因：踢的量级只有 σ·(1/√51) ≈ 2%，而它要修的
前提（长时效 σ=0 最好）本身已被推翻——**根本没有那笔代价要修**。`zm15` / `zmaB`
两条 config 不用再跑。

### 6.6 空间轴（length_scale）：无效

- ls 对**校准**没影响（SER 全程幅度 < 抖 σ 的 0.09）；对 RMSE/CRPS 有动作但**符号不稳**
  （240h 上两批差 7.8 个百分点、360h 符号直接翻）⇒ 批次相关，不是杠杆；
- 机理定论：ls ≥ 8 之上**没有分辨率**——留存模数从 ls=8 的 19.1 掉到 ls=32 的 0.61
  （31 倍），48h 之后 l8/l24/s04 不可分；ls=32 时非 DC 能量 94% 挤在 (f_y=0, f_x=±1)
  一对模上而 rank=16 需要 16 个正交方向 ⇒ 饱和。⇒ **ls 退化为又一个幅度旋钮，主要作用
  在 6–24h**，给不出「空间落点」；
- **与种子不可分**：基的 SeedSequence 含 `⌊length_scale×1000⌋` ⇒ ls 不同基就不同，
  l8 相对 l24 的那点优势不能归给尺度（同 ls 换 seed 的判别实验挂在未结项里）。

### 6.7 逐尺度结算（P4）：谱形已对，缺口是幅度不是尺度分配

`ar1_spread_spectrum.py`，口径 `P_s(k)=mean_m B(f_m−f̄)(k)`、`P_e(k)=B(f̄−o)(k)`、
`R(k)=√(P_s/P_e)`，球谐带 (1,4)(5,20)(21,40)(41,64)(65,128)。先过验证：aB/07-02 的
spread 与 rmse **七档逐位复现归档**（五位有效数字全同）。

**主结论：误差的谱形 ≈ 离散度的谱形**（三起报占比均值）：

| 块 | | 1_4 | 5_20 | 21_40 | 41_64 | 65_128 |
|---|---|---|---|---|---|---|
| 短 6–120h | 离散度 | 12.4% | 70.1% | 14.1% | 2.6% | 0.8% |
| | 误差 | 13.7% | 67.1% | 15.7% | 2.8% | 0.8% |
| 长 126–360h | 离散度 | 14.5% | 80.2% | 4.6% | 0.5% | 0.1% |
| | 误差 | 10.3% | 85.3% | 4.0% | 0.3% | 0.1% |

⇒ 没有「把扰动从大尺度挪到小尺度」能修的东西。唯一两个口径下三起报全同向的信号是
5_20 带（短过散 R≈1.12~1.22、长欠散 R≈0.79~0.91，随时效变号）；**小尺度（65_128）
占比比六个格子全 = 1.000，缺口不在小尺度**；1_4 / 21_40 / 41_64 两口径打架（小自由度
带比值本来就不稳），别读。

**机制（比数字重要）**：`amp_profile` 是标量 a(t) 乘在 ξ 上 ⇒ P_s(k) 整体 ×a(t)²，
对所有波数一视同仁——**它按构造就改不了尺度分配**。实测尺度分配已经基本对，这就是
aB 能逼近标定、却补不上最后一截的原因，也说明**继续调 a(t) 的水平是死路**（能做的
只有尾段抬幅度，见 §6.4 的外推警告）。

### 6.8 叠加与其它

- **`W32`（AR(1) ⊕ SPW 权重扰动）不跑**：方差可加，+48h 合并 SER ≈ 1.79，中段被推
  过头。「长时效的收益与短时效的代价由同一个 k₀ 支付」再次应验；
- 老 `fgvp_ens_ar1*` 族（s02/s06/s18）的 σ 档是**假阶梯**（SER@24 三条全 0.334），
  σ 没接进驱动侧 ⇒ **σ 阶梯只认 `ar1state` 族**；
- FuXi 侧（pt2）：代码就绪、自检 223 条全过、真图结构验收已过，**端到端出数待跑**
  （S0 底噪 = GPU 非确定性 ~0.2% 场变率，必须先量出，否则所有臂的 spread 缺下限）。

## 7 读数陷阱与边界（每条都踩过）

### 7.1 统计功效类

1. **起报间散布 ≫ 臂间效应**：同一个臂只换起报，z500 RMSE 24h 差 8~48%、360h 差 9~14%，
   而臂间效应只有 1~3% ⇒ **n=1 的读数一律无意义**，所有判定必须三起报同号；单起报
   只能筛「有没有崩」。
2. **跨批/跨推理根漂移 1~4% = 效应量本身**：同 config 同起报换一次推理根，s00@360h
   三次读数 774.1 / 784.9 / 792.7。要横比的臂必须**同批**。
3. **换卡数 = 换一次集合实现**：三个通道同时变——批长（cuBLAS kernel 选择）、图内原生
   ε 的成员分组（8 卡 7 类 → 4 卡 13 类）、驱动侧 ξ 的流本身（slot = m % world_size，
   51 条流全部重抽）。实测卡数效应主要落在 **spread/SER**（24h 差 3.1%）、落在 rmse 上
   小一个量级 ⇒ **绝对量（SER 数值、σ\*）别跨卡数对拍**；批内臂间差值不受影响（一阶共模）。

### 7.2 指标口径类

4. **`activity_ratio` 是 spread 的反读**：corr = −0.975（n=30）。它是确定性场指标
   （std(集合均值场)/std(实况场)），与 spread 的耦合是机械的；短时效没有横向分辨率
   （九臂 @24h 极差 0.12%）。**任何用它撑的「均值改善/流形」结论都要撤。**
5. **长时效 RMSE 优势要先剥幅度**：用 `a_o·√(1−ACC²)` 剥掉幅度后 −14% 只剩 −1.5%。
   长时效 RMSE 改善必须附 ACC 一起读。
6. **两条公式陷阱**：`√(RMSE²−spread²)` 不是 bias（正确是 −spread²/M，M=51 时退化）；
   `SER ≡ spread / rmse@ensemble`，分母是**集合口径** rmse。
7. **`scores.csv` 口径**：必须过滤 `region == ""`（档案混 tropics 行）；rmse 有两种
   product_kind、crps 只有 ensemble，按 `(metric, product_kind)` 取；`init_time` 用
   `[:10]`（`[:8]` 会把三条起报撞成一个键）。
8. **带功率类指标吃的是集合平均场**（`spherical_bands` / `zonal_spectrum` /
   `activity_ratio` 都是 specialized + ensemble_mean 降维）：集合平均压低距平 ⇒
   散得越少越「好看」（带增益与 r_long 相关 −0.951）。**带功率必须按残差读**，且均值
   质量拿 σ=0 的 D0/s00 当同源锚，不拿别的扰动臂。
9. **成员离散度的谱**评测流程给不了（同上），必须 `ar1_spread_spectrum.py` 离线算；
   它有一版**不能用**的实现（对离散度场本身做球谐带，R(k) 低到 0.03 而标量 SER≈0.9），
   判据是闭合检查：Σ_k P_s 必须能对回 4π·spread²。

### 7.3 SPA 特有类

10. **图指纹刻意不含 τ/a(t)/demean**（§4.4）：换它们**不触发重导图、别以为没生效**；
    反过来换锚点（targets）必须重导。诊断 a(t) 曲线是否真的是设计的那条，只能
    `ar1_amp_audit.py`。
11. **a(t) 折点 step 口径**：`NNN.nc` = 提前 NNN×6h = **code step NNN−1**（0 基）。
    aB 的 config 曾把 1 基表抄成 0 基 ⇒ 整条曲线晚 6h。**已实测：时均 σ 配对反而更好，
    别去修**——但要记录在案。
12. **σ=0 空转 ≠ 裸跑逐位相同**：短时效 ~1%、+240h 到 ~4.25% 的重现底噪（原生 ε +
    GPU 非确定性），这是所有判读的天花板。
13. **图内原生 ε 是不受控的第二噪声源**：onnxruntime 随机算子不给 seed 也确定性 ⇒
    按「worker 内第几次前向」对齐，成员被分进若干 ε 类；它 σ 无关，差分可解释，但
    「集合平均 ≡ 确定性场」这类话只能写到一阶。

### 9.3 一页话总结

- **SPA = 潜空间 AR(1) 强迫**：不动权重、每步喂 48 个数、低秩 + 空间平滑 + AR(1) 记忆的
  乘性潜状态扰动；一份图服务全部成员，成员差异只来自 ξ 种子。
- **机理定位**：SPW 的 τ=∞ 与图内噪声的 τ=0 是它的两端；骨干缺的是增长率不是幅度，
  SPA 把「时间相关」分离成独立自由度（P1 成立，A32 在 +48/72h 标定 1.09、无记忆端
  全程 0.30–0.57）。
- **旋钮判定**：σ 主控校准（σ\*≈0.092、σ>0.08 别外推）；τ 是真形状旋钮（v14 全同号
  −43%~−6%，改的是增长斜率，与 a(t) 必须联合扫）；length_scale 无效（ls≥8 无分辨率）；
  去均值作废；**注入锚点效应量最大（同 σ 差 ≥300 倍）且已定死在 decoder 入口**。
- **当前最好配置 = `aB`**（σ*(t) 实测表包络，校准 0.140，三起报全胜常数 σ族）；
  要一个数用常数 σ=0.10（0.160）。设计包络：先把 a(0) 顶到 s04 档再往上爬。
- **还差的 ~15% 是长时效 5_20 带的纯幅度缺口**（谱形已对、小尺度占比比全 = 1.000）；
  a(t) 是标量、按构造改不了尺度分配。
- **读数纪律**：三起报同号才算数；跨批/跨卡数不对拍绝对量；判据是 SER/CRPS 不是
  spread 大小；长时效 RMSE 附 ACC 才能读。
